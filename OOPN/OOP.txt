                                                          Interface
Q. what is interface ?
A= An interface is a blueprint of a class that define a set of abstract methods and by default  
   public static final variables. from java 8 interface can also have default and static method  
   with implementation. Java 9 further introduced private methods in interfaces. Interfaces are  
   mainly used to achieve abstraction, support multiple inheritance, and provide loose coupling .   

🔷 Why Use an Interface?
✅ Achieves Abstraction → Hides implementation details, defining only required behavior.
✅ Supports Multiple Inheritance → A class can implement multiple interfaces, avoiding conflicts.
✅ Encourages Loose Coupling → Reduces dependencies between components in a system.

Loose Coupling means:

Loose coupling means classes are not directly dependent on each other, they depend on abstractions (like interfaces), making the code flexible and easy to change.

Classes are independent of each other's implementation. They interact only through interfaces or abstract classes.


Q. why interface variables are  public static final ?
A = Interface variables public: because accessible anywhere and child class provide implement

   "Interface variables are static because they do not belong to any object (instance); they belong to the interface   
   itself. and can be accessed directly using the interface name.""
    
    Interface variables final: Interface variables are meant to be constants (fixed values).
    Since interfaces are designed to define behavior, not state, making variables modifiable would  
    go against this principle. Once assigned, the value cannot be changed. 
    final: Cannot be changed after initialization.
  
🔷 Common Interview Follow-Up Questions:
❓ Can an interface have concrete methods?
✔ Yes, from Java 8, interfaces can have default and static methods with implementation.

❓ Can an interface have constructors?
❌ No, because interfaces cannot be instantiated directly.

❓ What is the difference between an abstract class and an interface?
✔ Abstract Class: Can have constructors, instance variables, and method implementations.
✔ Interface: Cannot have instance variables, but supports multiple inheritance.

1.Code Reusability – Child classes reuse the methods of the parent class.

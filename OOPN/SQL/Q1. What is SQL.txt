Q1. What is SQL?
SQL (Structured Query Language) is a standard language used to communicate with databases. It helps in storing, retrieving, updating, deleting, and managing data in relational databases.

✅ What is a Relational Database?
A Relational Database is a type of database that stores data in the form of tables (also called relations). Each table is made up of rows and columns, and the data in different tables is related to each other using keys (like primary key, foreign key).

A Relational Database stores data in tables (rows and columns), where each table is related to others using keys like primary and foreign keys.

Types of Data Base

✅ 1. Relational Database (RDBMS)
Data stored in tables (rows and columns)

Uses SQL
Highly structured
🔹 Examples: MySQL, PostgreSQL, Oracle, SQL Server

✅ 2. NoSQL Database
Non-relational; used for unstructured or semi-structured data

Types include:

Document-based (e.g., MongoDB)
Key-Value (e.g., Redis)
Wide-Column (e.g., Cassandra)
Graph (e.g., Neo4j)

✅ 3. In-Memory Database
Stores data in RAM (Memory) instead of disk
Very fast, used in real-time apps
🔹 Examples: Redis, Memcached


Q2. What are the different types of SQL commands?
➡️ DDL, DML, DQL, DCL, TCL 

✅ 1. DDL (Data Definition Language)
Used to define or modify database structure

Command	Use
CREATE	Create table or database
ALTER	Modify existing table
DROP	Delete table or database
TRUNCATE	Remove all rows from a table (faster than DELETE)

✅ 2. DML (Data Manipulation Language)
Used to manipulate actual data

Command	Use
INSERT	Add new data
UPDATE	Modify existing data
DELETE	Remove data


✅ 3. DQL (Data Query Language)
Used to query data

Command	Use
SELECT	Fetch data from one or more tables


✅ 4. DCL (Data Control Language)
Used to control access and permissions

Command	Use
GRANT	Give user access          //  GRANT is used to give permission to other users.
REVOKE	Take away user access      //  Remove permission from user

✅ 5. TCL (Transaction Control Language)
Used to manage database transactions

Command	Use
COMMIT	Save changes permanently
ROLLBACK	Undo changes     // undo mean  ✅ Undo means to cancel or reverse the recent changes and go back to the previous state.

SAVEPOINT	Set a save point in a transaction

NOTE= ❌ No, once you COMMIT, you cannot undo the changes using ROLLBACK.

Q3. What is the difference between DELETE, TRUNCATE, and DROP?

 1. DELETE
Used to remove specific rows from a table.

🔹 You can use WHERE clause

🔹 Can rollback using ROLLBACK

🔹 Triggers get fired
🔹 Slower (logs each row)

⚡ 2. TRUNCATE
Used to remove all rows from a table quickly.

❌ Cannot use WHERE

❌ Cannot rollback (in most databases)

❌ Triggers do not fire

⚡ Much faster than DELETE


🧨 3. DROP
Used to delete the entire table structure (table is gone forever)

DROP → command is used to delete table and database


❌ All rows + table definition is deleted

❌ Cannot rollback

❌ Table no longer exists


✅ 1-Line Differences:
DELETE → Deletes specific rows (can undo).

TRUNCATE → Deletes all rows (no undo).

DROP → Deletes entire table (structure + data).  // DROP → command is used to delete table and database

Q7. What is a Foreign Key?

A foreign key is used to connect one table to another by referring to the primary key of the other table.

CREATE TABLE department (
  dep_id INT PRIMARY KEY AUTO_INCREMENT,
  dep_name VARCHAR(20)
);

CREATE TABLE employee (
  id INT PRIMARY KEY AUTO_INCREMENT,
  emp_name VARCHAR(20),
  dep_id INT,
  FOREIGN KEY (dep_id) REFERENCES department(dep_id)
);

Q9. What is the difference between NULL, 0, and '' ?

NULL means no value or unknown value. It represents missing or undefined data in a column.
👉 Example: A user didn’t enter their email — it's NULL.

0 is a valid numeric value. It means the value exists and is zero.
👉 Example: A student scored 0 marks — it's still a valid score.

'' (empty string) is a non-null but empty text. It means value was provided, but it's blank.
👉 Example: A user entered an empty name — it's ''.

✅ Summary line to impress interviewer:
NULL means no data, 0 means numeric zero, and '' means empty text, but all three are different and treated separately in SQL.

Q19. Difference between correlated and non-correlated subquery?

✅ 1. Non-Correlated Subquery
A non-correlated subquery runs independently of the outer query.
It is executed only once, and the result is used by the outer query.

SELECT name
FROM employees
WHERE salary > (
  SELECT AVG(salary) FROM employees
);


✅ 2. Correlated Subquery
A correlated subquery depends on the outer query.
It is executed once for every row of the outer query.

🔧 Example:

SELECT name
FROM employees e1
WHERE salary > (
  SELECT AVG(salary)
  FROM employees e2
  WHERE e1.department = e2.department
);

Q20. What is the difference between IN, ANY, and ALL?

1. IN
Checks if a value exists in a given list or subquery result.

1. IN – Match with any value from a list

WHERE column IN (value1, value2, value3)


🔧 Example:
SELECT name
FROM employees
WHERE department_id IN (1, 2, 3);


✅ 2. ANY
Compares a value to any value returned by a subquery using comparison operators like =, >, <.


2. ANY – Compares with any value from a subquery

WHERE column > ANY (subquery)



🔧 Example:

SELECT name
FROM employees
WHERE salary > ANY (
  SELECT salary FROM employees WHERE department_id = 2
);


✅ 3. ALL
Compares a value to all values returned by a subquery. The condition must be true for every row.

 3. ALL – Compares with all values from a subquery


WHERE column > ALL (subquery)
🔧 Example:

SELECT name
FROM employees
WHERE salary > ALL (
  SELECT salary FROM employees WHERE department_id = 2
);

 Q35. What is a Transaction in SQL?
A transaction is a group of SQL statements that run together as one unit.

🔸 Either all statements work, or none of them work.


A transaction is a sequence of one or more SQL operations that are executed as a single unit of work.
Either all changes are saved (COMMIT) or none are saved (ROLLBACK) if something goes wrong.


BEGIN;

UPDATE accounts SET balance = balance - 1000 WHERE id = 1;
UPDATE accounts SET balance = balance + 1000 WHERE id = 2;

COMMIT;


Q36. What are ACID properties?

ACID stands for the four key properties of a transaction that ensure data accuracy and reliability in databases.


 🔹A – Atomicity
🔸 All or nothing happens // "Either everything happens, or nothing happens."

If one part of the transaction fails, the whole transaction is rolled back.

Example:
Money deducted from Account A but not added to Account B → ❌ should rollback.

🔹 C – Consistency

🔸 Data must always be valid before and after the transaction.
   It must follow all rules (constraints, foreign keys, etc.)


🔹 I – Isolation
🔸 Transactions run independently of each other.
One transaction’s changes should not affect another running transaction.


🔹 D – Durability
🔸 Once a transaction is committed, its changes are permanently saved,
even if the system crashes.


🔸 Once a transaction is successful (committed), its data is saved forever —
even if your computer crashes, power goes off, or system restarts.

1.Find the second highest salary

Syntax :

select column_name
from Table_name
ORDER By column_name DESC
LIMIT 1 OFFSET 1;

select salary
from employee
ORDER By salary DESC
LIMII 1 OFFSET 1;

2.Find duplicate records in a table

select column1, column2, count(*)
from table_name
Group By column1, column2
Having count(*)>1;

Example :

select name, email, department, count(*)
from employee
Group By name, email, department
Having count(*) >1;


 If you want to see full duplicate rows (with IDs)

SELECT *
FROM employees
WHERE (name, email) IN (
  SELECT name, email
  FROM employees
  GROUP BY name, email
  HAVING COUNT(*) > 1
);

14.Find the number of employees hired each year

Select YEAR(hire_date) AS hire_year,  count(*) AS total_hired
from employees
group by year(hired_date)
order by hire_year; 
 
OR

select YEAR(hire_date), count(*) AS total_year
from employee 
group by YEAR(hire_date)
order by YEAR(hire_date);

YEAR(hire_date)
✅ YEAR() is a built-in SQL function.

It takes a date value (like '2024-01-03') and extracts just the year (like 2024).

So if hire_date = '2023-07-15', then YEAR(hire_date) gives 2023.

15.Perform a SELF JOIN to find employees and their managers

SELECT 
  e.name AS employee, 
  m.name AS manager
FROM 
  employee e
JOIN 
  employee m 
ON 
  e.manager_id = m.emp_id;

OR

select e.name, m.name
     from employee AS e
     join employee AS m
    
  ON e.manager_id = e.emp_id;

                               SQL Joins

Q. what is sql joins
A= SQL JOINs are used to combine data from two or more tables based on a common column. They  
   help fetch related information stored in different tables.


Note=  Column names do not need to be the same.
       Column data types and values should be the same

🔹Types of SQL JOINs:

1.INNER JOIN 
2.LEFT JOIN (LEFT OUTER JOIN)
3.RIGHT JOIN (RIGHT OUTER JOIN):
4.FULL JOIN (FULL OUTER JOIN): 


1.INNER JOIN :Returns only the matching rows from both tables. based on the join condition.


   

. SYNTAX 

SELECT COLUMN_name
FROM TableA
INNER JOIN TableB
ON TableA.column_name= TableB.column_name

For Example customer and payment Table

select *
from customer AS c       // AS mean Alyes 
INNER JOIN payment AS p  //
on c.customer_id =p.customer_id;


2.LEFT JOIN: Returns All records from the left table and the matched records from the right table.
              If there is no match in the right table, NULL values are returned for the right table's  
              columns.  

Left Join SYNTAX 

select column_name
from TableA 
LEFT JOIN TableB
on TableA.column_name= TableB.columnB    

NOTE: left side left table ex(TableA) and right side right Table ec(TableB)

For Example customer and payment Table


select *
from customer AS c
Left Join payment AS p
on c.customer_id= p.customer_id;


3.RIGHT JOIN: Returns All records from the right table and the matched records from the left table.
              If there is no match in the left table, NULL values are returned for the left table's  
              columns.

SYNTAX

select *
from TableA 
Right Join TableB
TableA.column_name=TableB.column_name

For Example customer and payment Table

select *
from customer AS c
Right Join payment AS p
c.customer_id= p.customer_id;


4. FULL JOIN (FULL OUTER JOIN):
Returns all records from both tables — the matched records, as well as the unmatched records from both sides.

If there is no match in the left table, NULL values are returned for the left table’s columns.

If there is no match in the right table, NULL values are returned for the right table’s columns.

Syntax :

select column_name
from TableA AS A
FULL JOIN TableB AS B
ON A.id =B.id;






✅ Why we write ON in SQL JOINs?
We write the ON keyword to tell how the two tables are related — i.e., which column should be used to match rows from both tables.

“Match rows where the employee’s id in TableA is the same as the emp_id in TableB.”



A SELF JOIN is when a table is joined with itself.

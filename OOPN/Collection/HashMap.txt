                                HashMap

✅ 1. What is a HashMap?
A HashMap is a part of map interface. It stores data in key-value pairs.

underline data structure is hashtable.



Duplicate keys not allowed, but duplicate values are allow.
hashmap is notsynchronize 
it is not thread safe
Allows one null key and multiple null values
it introduce 1.2. it is not a legacy class
if you don't need a thread safe, and you want better performance you should use hashmap.


✅ 2. Basic Syntax OF HashMap

HashMap<String Integer> map= new HashMap<>();
         Key    Value

Here, String is the key type, and Integer is the value type.

✅ 3. Common Methods
 
   Method  
 
1.put(key, value)                 //put() method add the data 
2.get(key)                        //get() method return the value corresponding to the key  
3.remove(key)                     //remove() method remove key-value pair
4.containsKey(key)                //containsKey() method check if the key exists and return true false  
5.containsValue(value)            //containsValue() method check if the value exists and return true false
6.size()                      //size() returns the number of key-value pairs currently stored in the HashMap.
7.isEmpty()                  //isEmpty() method returns true if the map has no entries
8.clear()                   //Remove all entries

What is getOrDefault() in Java HashMap?
🔹 Purpose:
It returns the value for a key if it exists, otherwise returns a default value you provide.

Syntax:
map.getOrDefault(key, defaultValue);



 Entry is an interface that represents a single key-value pair in a map.

It has three important methods:

getKey(): Retrieves the key.

getValue(): Retrieves the value associated with the key.

setValue(V value): Allows updating the value of a specific key.

It provides methods to get the key and get the value.

It's commonly used to iterate through a Map when you need both keys and values.

1.Single inheritance

single child class, and single parent class this types of inhertance is called Single inheritance.

"When a single child class inherits from a single parent class, this type of inheritance is called Single Inheritance."

Key Points:
✅ One parent, one child → Single Inheritance.
✅ Uses the extends keyword to inherit from the parent class.
✅ Promotes code reusability and efficiency.


2.multilevel Inheritance

what is multilevel Inheritance

"When a child class inherits from a parent class, and then another child class inherits from that child class, forming a chain of inheritance, this type of inheritance is called Multilevel Inheritance."



Whatever method available inside A class automatically available to B class. Whatever method available inside to B class automatically available to c class this type of inheritance is called multilevel inheritance

✅"In multilevel inheritance, whatever methods are available in class A are automatically available in class B. Similarly, whatever methods are available in class B are automatically available in class C. This type of inheritance is called multilevel inheritance."

Advantages of Multilevel Inheritance:
✅ Code Reusability – Properties and methods are reused at multiple levels.
✅ Extensibility – Additional features can be added without modifying existing code.
✅ Method Overriding – Child classes can modify inherited methods for specific behavior.

Q: Why does this problem occur only in classes but not in interfaces?
A: In classes, multiple methods can have implementations, leading to ambiguity about which method to execute. However, in interfaces, only method declarations are present without implementations, so this issue does not arise.

4.Hierarchical Inheritance 

"When multiple child classes inherit from a single parent class, this type of inheritance is called hierarchical inheritance."


 Note: When multiple classes extend the same parent class, it is called Hierarchical Inheritance.


 It is a reverse of multiple inheritance 

Note= All class extend same class is called Hierarchical Inheritance  

for Example

class A{


}

class B extend A{

}

class C extends A{

}

Advantages of Hierarchical Inheritance:

1.Code Reusability – Child classes reuse the methods of the parent class.

2.Easy to Maintain – Changes made to the parent class are inherited by all the child classes, making the system easier to maintain.
3.Logical Structure – It reflects a real-world relationship between the parent and child classes.


Disadvantages of Hierarchical Inheritance:

1.Tightly Coupled Classes – Changes in the parent class could affect all child classes.

2.Reduced Flexibility – All child classes inherit the same methods from the parent, which may not always be ideal for  
  all child classes.

•Types of relationship

There are two types of relationship
1.Is-A  relationship (Inheritance)
2. Has-A relationship (Association)

1.Is-A relationship: Whenever one class inherits another class, it is called an IS-A relationship

Q.how we can achive is-a relationship
ans.IS-A relationship can simply be achieved by using extends Keyword.

Advantage of IS-A relationship 
Code Reusability.
Reduce redundancy.


Disadvantages:
IS-A relationship is tightly coupled, which means changing one entity will affect another entity.


2. Has-A relationship: (Association) Whenever an instance of one class is used in another class, it is called HAS-A 
                       relationship.
                      
                      One class contain another class is called has a relationship     
                      In Java, a has-a relationship is when one class has a reference to another class  

   Advantages of Has-a relationship 

 1.Code Reusability: Instead of rewriting code, one class can use another class’s functionality by containing an object of it.
 2. Loose Coupling (Flexibility & Maintainability)


   There are two forms of Association 

1.Aggregation(weak bounding)
2.Composition(strong bounding)

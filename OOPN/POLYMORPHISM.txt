Q. In method overloading, if the argument is a child class and does not exactly match any method   
    parameter, what will happen?
A. If a method with an exact match for the child class argument is not found, Java will look for 
   the closest matching superclass method in the overloaded methods. If a suitable parent class 
   parameter is available, Java will promote the child object to the parent type and call that 
   method. Otherwise, it 
   will result in a compilation error.

Q. why ambiguous error comes tell
A= Java checks which method to call based on the argument type.
   null can match both String and StringBuffer because both are reference types.
   Java tires to find the best match, but:

   String is not a subclass of StringBuffer.
   StringBuffer is not a subclass of String.

   Java cannot decide which method to call.

   Because of this confusion, Java gives a compilation error (ambiguous method call).

                 DIFFERENCE BETWEEN Method OVERLOADING AND OVERRIDING


Difference between method overloading and overriding

.Overloading

1️⃣ Method name must be the same.
2️⃣ Argument type must be different (at least in number, type, or order).
3️⃣ Private, final, and static methods can be overloaded.
4️⃣ Return type does not play a role in method overloading; overloading requires a different parameter list.
   Return type is no restriction in overloading 
5️⃣ Throws clause has no restriction in method overloading.
6️⃣ In overloading, method resolution is always handled by the compiler based on the reference type.
7️⃣ Overloading is also known as compile-time polymorphism, static polymorphism, and early binding.

                                   POLYMORPHISM

one name with multiple form is known as polymorphism

methods having same name but different argument types

Note= same method name we can use different type of argument (more flexibility)

🚀 It makes the code more flexible and reusable

There are Two types of polymorphism 

1.compile time polymorphism 
2.runtime polymorphism 


🔹 Advantages of Polymorphism in Java



1️⃣ Code Reusability 🛠️

The same method name can be used for different purposes, reducing duplicate code.
Example: A single add() method can handle both integers and doubles.


2️⃣ Flexibility & Maintainability 🔄

Polymorphism allows modifications in code without affecting existing functionality.
Example: If a new subclass is added, the existing code does not need major changes.

✔ Improves readability and maintainability.

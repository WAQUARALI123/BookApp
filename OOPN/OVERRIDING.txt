                     RULES OF METHOD OVERRIDING

1. Method names must be same and argument type must be same. including order // mean method signature

2. return type must be same in overriding but this rule is applicable until 1.4 version. from 1.5 version 
   onward covariant return type is also allow.

Q. In overriding different return type is allowed or not ?   
A= before 1.5 version must have same return type. but after 1.5 version covariant return type.it is possible   
   to have different return type in overriding. but child class method return should be sub of parent class
   method return this concept is known as covariant return type 

Q. what is covariant return type
A= child class method return should be sub of parent class method return this concept is known as covariant   
   return type 


Q. parent class method return object and child class method return is String 
A= true

Q. parent class method return String and child class method return is object 
A= this is not covariant return type false

Q. parent class method return double and child class method return int. is it valid or not ?
A= It is not valid 
Note= covariant return type concept is only applicable for object type. but not for primitives   


for Example for Covariant

return null;

                 DIFFERENCE BETWEEN Method OVERLOADING AND OVERRIDING


Difference between method overloading and overriding

.Overloading

1️⃣ Method name must be the same.
2️⃣ Argument type must be different (at least in number, type, or order).
3️⃣ Private, final, and static methods can be overloaded.
4️⃣ Return type does not play a role in method overloading; overloading requires a different parameter list.
   Return type is no restriction in overloading 
5️⃣ Throws clause has no restriction in method overloading.
6️⃣ In overloading, method resolution is always handled by the compiler based on the reference type.
7️⃣ Overloading is also known as compile-time polymorphism, static polymorphism, and early binding.

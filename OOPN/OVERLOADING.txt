CASE:1

Type promotion in method overloading means that if there is no exact match for a method’s parameter, Java automatically converts a smaller data type into a larger one. This concept is known as automatic type promotion.

Q in overloading parent argument and child argument which argument will get highest priority

Q. in overloading child argument not exact match argument what will happen
A.= pass parent argument

Q. In method overloading, if the argument is a child class and does not exactly match any method   
    parameter, what will happen?
A. If a method with an exact match for the child class argument is not found, Java will look for the   
   closest matching superclass method in the overloaded methods. If a suitable parent class parameter is 
   available, Java will promote the child object to the parent type and call that method. Otherwise, it 
   will result in a compilation error.

public class Test2{

public void m(String s){

System.out.println("string method");
}

public void m(StringBuffer sb){

System.out.println("StringBuffer method");
}

public static void main(String[] args){

Test2 t1=new Test2();

t1.m1("abc");
t1.m1(new StringBuffer("aaa"));
t1.m1(null); // in this case compilation error compiler will confuse like ambiguous error
}
}

Q. why ambiguous error comes tell
A= Java checks which method to call based on the argument type.
   null can match both String and StringBuffer because both are reference types.
   Java tires to find the best match, but:

   String is not a subclass of StringBuffer.
   StringBuffer is not a subclass of String.

   Java cannot decide which method to call.

   Because of this confusion, Java gives a compilation error (ambiguous method call).

Q. what is tightly encapsulation 
A= If all instance variables of a class are declare private variable such type of class is called  
   tightly encapsulation  
   
✅ If all instance variables of a class are declared as private, then that class is considered tightly encapsulated. 


✅ "if a parent class is not tightly encapsulated, the child class can be tightly encapsulated by  
    declaring all its instance variables as private


✅ Advantages of Encapsulation (Key Points)
1️⃣ Data Hiding (Security) – Prevents direct access to data, ensuring controlled modification via methods.
2️⃣ Prevents Accidental Data Modification – Only setter methods allow controlled updates with validation.
3️⃣ Increased Maintainability & Flexibility – Internal implementation changes don’t affect external code.
4️⃣ Improves Code Reusability – Encapsulated classes can be reused in multiple applications.
5️⃣ Easier Unit Testing – Allows testing specific methods independently.
6️⃣ Improves Readability & Organization – Groups related variables and methods for better structure.

Abstract class Vs Abstract method

"Note: In an abstract class, every abstract method must be implemented in the child class (subclass); otherwise, a compile-time error will occur."

"An abstract class requires all its abstract methods to be implemented in the child class (subclass); otherwise, a compile-time error will occur."


Q. we don't want to all abstract method providing implementation in child class how we can do.
Ans= we can declare child class as abstract then not compulsory  all abstract method providing implementation in child class 
                                          OR

Q: What if we don't want to implement all abstract methods in the child class?
A: We can declare the child class as abstract. In that case, it is not compulsory to implement all abstract methods in the child class.


Q:   Who is responsible for implementing the remaining abstract methods?
Ans: The next-level child class (e.g., a sub-sub child class) is responsible.

Q. what is the use of declaring abstract method in parents class  
A= If i am not declare abstract method in the parent class. but child class may provide or may not be provide
   implementation. if we declare  abstract method in parent class. then we mandatory to provide implementation 
   in child class. 
 
Q: What is the use of declaring an abstract method in the parent class?
A: If we do not declare an abstract method in the parent class, the child class may or may not provide an  
   implementation. However, if we declare it as abstract, then it becomes mandatory for the child class to provide an   
   implementation.

For Example= if we define vehicle class and declare abstract method getnoOfWeels() so child class mandatory  provide an implementation not skip.

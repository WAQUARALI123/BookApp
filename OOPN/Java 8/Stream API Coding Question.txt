✅1.List of names W se start hone wale names uppercase me return karo
   . Convert a list of strings to uppercase

  List<String> names = Arrays.asList("abc", "waquar", "dell");

   List<String> result= names.stream()
  .filter(name -> name.startsWith("w"))
  .map(String::toUpperCase)
  .collect(Collectors.toList());
   
   System.out.println(result);

✅ 3.List se duplicate remove karo
    . Remove duplicates from a list


    List<Integer> number = Arrays.asList(1,2,3,1,2,3,4,5,6,2,5);
	 
     List<Integer> removeDupli= number.stream()
     .distinct()    // ✅ removes duplicates
     .collect(Collectors.toList());
	 
	 System.out.print(removeDupli);
		
✅ Key Points:
Sirf unique elements ko allow karta hai.

Order maintain karta hai (original list ka).

Works similar to Set behavior, but in stream style.

✅ 6. List ko descending order me sort karo
     . Sort a list in descending order


List<String> names = Arrays.asList("dell", "abc", "zebronic");

List<String> sortedDesc = names.stream()
    .sorted(Comparator.reverseOrder())  // 🔽 Reverse (descending) order
    .collect(Collectors.toList());

System.out.println(sortedDesc);  // Output: [zebronic, dell, abc]
